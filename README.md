# AnimeHunt

AnimeHunt is a modern anime character discovery web app built with **React + Vite**, where users can explore anime characters, play fun quizzes, and save their favourite characters — all in one place.

Designed with a clean UI, smooth UX, and anime-friendly aesthetics 💖

---

##  Features

- 🔍 **Search Anime Characters**  
  Instantly search characters fetched from the Jikan (MyAnimeList) API.

- ❤️ **Wishlist / Favourites**  
  Like your favourite characters and access them anytime.

- 🧠 **Guess the Anime Quiz**  
  Fun quiz with clues to test your anime knowledge.

- 👤 **Login System (Local Storage based)**  
  User stays logged in even after page reload or browser restart until logout.

- 📱 **Fully Responsive Design**  
  Works smoothly on mobile, tablet, and desktop screens.

- 📌 **Sticky Navbar**  
  Clean, fixed navbar with smooth scrolling experience.

- 🎨 **Aesthetic UI**  
  Custom color palette (#5A0E24 & #F7C6C7) with modern styling.

---

## 🛠️ Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **Jikan API (MyAnimeList)**
- **Local Storage**
